All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). This project uses semantic versioning.

## [Unreleased]

## [1.0.0] - 2026-09-29

### Added

- Initial ForgePy CLI with seven project templates.
- Interactive and fully non-interactive creation flows.
- Provider, vector-store, testing, Docker, Python, and package-manager options.
- Transactional filesystem generation and project-name validation.
- Generated-project compilation and metadata tests.
- Cross-platform CI and an intentional Trusted Publishing release workflow.
- Wheel, source-distribution, installed-package, and transactional safety verification.
- Security policy, code of conduct, and repository contribution templates.
- Learning, Standard, and Minimal guidance levels with Learning-mode `PROJECT_GUIDE.md` files.
- Optional `--setup` workflow for native pip or uv environment setup, compilation, and starter-test verification.

### Changed

- Hardened template path and project-name validation.
- Improved generated packaging, Docker instructions, and src-layout projects.
- Setup failures preserve generated projects and report the exact recovery command.
- Generated README setup commands respect both package-manager and test selections.
